## Build a Console Calculator Application

---

### **Objective**

The goal of this assignment is to design and implement a command-line calculator program. Through this project, you will practice core programming concepts including **conditional statements** (`if-else`, `switch`), **modular programming** (methods/functions), **input validation**, and **loops**.

---

### **Project Requirements**

#### **1. Functional Requirements**

Your calculator must support the following five basic mathematical operations:

- Addition ($a + b$)
- Subtraction ($a - b$)
- Multiplication ($a \times b$)
- Division ($a \div b$, with error handling for division by zero)
- Modulus / Remainder ($a \pmod b$)

#### **2. Technical Requirements**

- **Modular Design:** Create separate methods/functions for each arithmetic operation (e.g., `add()`, `subtract()`, `multiply()`, `divide()`).
- **Control Flow:**
  - Use a **`switch` statement** or a chain of **`if-else` statements** to direct user input to the correct operation method.
  - Use a **loop** (e.g., `while` or `do-while`) so the user can perform multiple calculations without restarting the program.
- **Input Validation:** Handle edge cases gracefully, such as dividing by zero or entering an invalid operator.

# SQL Server Online Editor & Compiler Reference

This document serves as a quick reference guide and overview for writing, testing, and sharing T-SQL queries using the **[OneCompiler SQL Server Online Editor](https://onecompiler.com/sqlserver)**.

---

## Overview

Microsoft SQL Server is an enterprise-grade relational database management system (RDBMS) utilizing **T-SQL (Transact-SQL)**, which extends standard SQL with procedural programming, local variables, and robust database management tools.
